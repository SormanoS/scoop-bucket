# Quboid Scoop Bucket

Official [Scoop](https://scoop.sh/) bucket for [Quboid](https://github.com/SormanoS/quboid) — keyboard window snapping for Windows 10 and 11 with Rectangle's default shortcuts.

## Install

```powershell
scoop bucket add quboid https://github.com/SormanoS/scoop-bucket
scoop install quboid/quboid
```

## Update

```powershell
scoop update quboid
```
